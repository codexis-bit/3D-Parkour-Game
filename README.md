# MOMENTUM

Ein schnelles 3D-Parkour-Spiel im Browser – Wall Runs, Wall Jumps, Slides und ein Grappling Hook.
Gebaut mit **Three.js**, **Rapier** (Physik) und **TypeScript**.

> 🚧 In Entwicklung – siehe Meilensteine in der Commit-Historie.

## Lokal starten

```bash
npm install
npm run dev
```

## Skripte

| Befehl            | Zweck                                    |
| ----------------- | ---------------------------------------- |
| `npm run dev`     | Dev-Server mit Hot Reload                |
| `npm run build`   | Typecheck + Produktions-Build in `dist/` |
| `npm run preview` | Build lokal ansehen                      |
| `npm test`        | Unit-Tests (Vitest)                      |
| `npm run lint`    | ESLint                                   |
| `npm run format`  | Prettier                                 |
